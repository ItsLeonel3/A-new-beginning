# LEOBAY23 Legacy Hub

Portada moderna para conservar y presentar la antigua web Ghost y LEOBAY PLAYER.

- `legacy/` — versión Legacy original.
- `player/` — ejecutable y código fuente de LEOBAY PLAYER.
- `index.html` — nueva portada.
- `style.css` / `script.js` — diseño y herramienta de reproducción web.

Compatible con GitHub Pages. El LEOBAY PLAYER original es una aplicación Windows; la herramienta web incluida es una demo independiente para reproducir archivos locales en el navegador.
